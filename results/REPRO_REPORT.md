# LMD2023 再現実験レポート：論文値との比較

- 対象論文：Smiliotopoulos, Kambourakis, Barbatsalou. *On the detection of lateral movement through supervised machine learning and an open-source tool to create turnkey datasets from Sysmon logs.* IJIS 22:1893–1919 (2023). doi:10.1007/s10207-023-00725-8
- 作成日：2026-10-13
- 範囲：浅層モデル14種（表11）の再現と、DNN（表13）の部分的な再現。**このレポートは論文値との比較だけを扱います。** データリークなどの批判的検証は別途まとめます。

## 1. 要約

| 観点 | 結果 |
|---|---|
| 非木系モデル（LR・SGDC・LinearSVC・NB・KNN・CatBoost） | **ほぼ再現できた。** 著者の行列ファイルで、AUC の差は 0.02〜1.5pt、Accuracy の差は 0.3pt 以内。LinearSVC は AUC 92.87（論文 92.89）、Acc 98.66（論文 98.67）でほぼ一致。 |
| 木系モデル（LightGBM・DT・RF・ET・Bagging） | **論文値に届かない。** 表10のハイパーパラメータでは AUC が 4〜12pt、Acc が 0.8〜2.0pt 低い。論文の最良モデル ET は AUC 87.72 / weighted F1 97.62（論文 99.84 / 99.41）で、むしろ木系の中で最も低い。 |
| ET の枝刈りなし版（感度分析） | `ccp_alpha` を外すと weighted F1 が 99.04 / Acc が 99.09 になり、論文値に近づく。表10の値と実際に使われた設定が異なる可能性がある。 |
| 論文の指標の計算方法 | **AUC は予測ラベル（hard label）から計算したもの**と判断できる（非木系で論文値と一致）。予測確率から計算した AUC は全モデルで 99.5 以上になる。Precision / Recall / F1 は、モデルによって **weighted 平均（LR・NB）と macro 平均（SGDC・LinearSVC）が混在**しているとみられる。 |
| 分割方式 | 75/25 のホールドアウトと 10分割交差検証の差は小さく（weighted F1 で最大 0.20pt、Acc で 0.11pt）、どちらで評価しても結論は変わらない。 |
| 公開版の生データから作った15特徴（public15） | 大半のモデルで論文値を上回り、LR・LinearSVC・LightGBM・CatBoost は **F1 = 100.00**。 |
| DNN | **再現できなかった**（MLP・AE・CNN のみ実施。RNN・LSTM は計算時間の都合で中止）。 |

## 2. 実験設定

### 2.1 データ
論文と同じデータそのものは公開されていないため、2種類のデータで再現しました。

| 名前 | 内容 | 行数 | ラベル内訳（Normal / EoRS / EoHT） |
|---|---|--:|---|
| 論文（表6） | — | 1,752,890 | 1,611,637 / 110,746 / 30,507 |
| **authors** | 著者の行列ファイル `full-csv(Evaluated Titles).csv`（2023-01-31付、90特徴）。著者の特徴量重要度スクリプトがこのファイルを読み込んでいて、論文の DNN 入力次元90とも一致する。 | 1,777,930 | 1,611,637 / 110,746 / **55,547** |
| 公開版の生データ | 公開 LMD-2023 の 1.75M 版「Checked」（2024-03付）のラベル付きCSV | 1,752,836 | 1,611,619 / 110,710 / 30,507 |
| **public15** | 上の生データから、論文と著者スクリプトの手順で15特徴を作り直したもの（One-Hot と MinMax 変換で75列） | 1,723,300 | 1,590,353 / 106,263 / 26,684 |

- authors は、Normal と EoRS の件数が論文と一致しますが、**EoHT が25,040件多くなっています**。
- 公開版の生データは、ラベル件数が論文とほぼ一致します。ただしタイムスタンプが論文の出版後（2023年12月まで）に及んでいて、論文で使われた版とは異なります。
- public15 で除いた行（'-' の行など）は29,536件です。論文では66,150件と書かれています。公開版に同梱の前処理済みCSV（1,723,308行）とはほぼ一致しました。

### 2.2 評価方法
- **75/25 ホールドアウト：** `train_test_split(test_size=0.25, stratify=y, random_state=42)`。論文に書かれた各foldの件数（学習1,314,668件／テスト438,223件）は、データ全体を75/25に1回分けたときの件数と一致するので、これを再現案として採用しました。authors では学習1,333,447件／テスト444,483件です。
- **層化10分割交差検証：** 論文の本文に書かれている方式です。`StratifiedKFold(10, shuffle=True, random_state=42)` で、各foldは学習1,600,137件／テスト177,793件です。authors で実施しましたが、1foldに約1時間かかるモデル（LR と Bagging の RF・ET・CB）はホールドアウトだけにしました。

### 2.3 指標
- **AUC（hard）：** LabelBinarizer で正解ラベルと**予測ラベル**を one-vs-rest に展開し、macro 平均したもの。論文の記述（"utilizes … the test … along with the equivalent predicted fractions"）と、博士論文 p.109 の記述に従いました。
- **AUC（score）：** 予測確率（または決定関数の値）から計算した、標準的な one-vs-rest の macro AUC。参考値です。
- **F1：** 論文では平均方式が書かれていないため、weighted と macro の両方を示します。

### 2.4 モデルとハイパーパラメータ
表10と5.1.1節に従いました。そのままでは実装できなかった点は、次のように対応しました。

| モデル | 論文との違い |
|---|---|
| LR | elasticnet の `l1_ratio` が書かれていないため0.5とした。multinomial は sklearn 1.9 の既定値。 |
| SGDC | 表10の `max_iter=5e-3` は反復回数として無効なので、既定値の1000とした。 |
| DT | `max_features='sqrt'` は本文から取った（表10には記載がない）。 |
| CatBoost | `CrossEntropy` は2クラス専用なので、`MultiClass` とした。 |
| Bagging | 基本推定器は、それぞれ表10の設定のまま使った。 |
| CNN・LSTM | 実数値の入力に Keras の Embedding 層は適用できないため、各特徴量を時系列の1ステップとして入力した。 |
| AE | 教師あり分類器としての構成が書かれていないため、エンコーダ・デコーダ型の全結合層に softmax の出力層を付けた。 |

### 3.2 論文の Precision / Recall / F1 はどの平均方式か
各モデルについて、論文値に近いのが weighted 平均と macro 平均のどちらかを調べました。「誤差計」は P・R・F1 の差の絶対値の合計（pt）です。

| SGDC | 92.49 | 98.38 | 93.14 | 90.03 | 98.46 | 88.97 | 91.21 | 98.41 | 90.89 | macro（誤差計 w=21.5, m=2.0） |

## 4. 所見（再現性について）
1. **非木系モデルは、著者の行列ファイルと hard label の AUC を使うと再現できます。** 特に LinearSVC と LR は小数点以下まで近い値になりました。論文の実験は、このファイル（またはそれに近いもの）で、予測ラベルからAUCを計算して行われたと考えられます。
2. **論文の表には、平均方式の異なる値が混在しているとみられます。** Precision / Recall / F1 は、モデルによって weighted と macro が使い分けられていて、表11のモデル間比較（例：「SGDC の F1 が最低」）はそのまま比べられません。
3. **木系モデルは、論文の表10どおりの設定では論文値を再現できません。** 論文で最良とされた ET は、表10の設定では木系で最も低い結果になりました。枝刈りなしで論文値に近づくことから、論文に書かれたハイパーパラメータと実際に使われた設定が食い違っている可能性があります。
4. **評価方法の違いは結果にほとんど影響しません。** 論文の本文（10分割交差検証）と、論文の件数から推定した方式（75/25の1回分割）のどちらでも、同じ水準の値が出ます。
5. **データの版によって結果が大きく変わります。** 公開版の生データから作った15特徴では、線形モデルも含めて F1 = 100% に達し、論文値を上回ります。論文の数値は、公開版のデータでは確認できません。
6. **データ件数が論文と一致しません。** 著者の行列ファイルは EoHT が論文より25,040件多く、公開版はタイムスタンプが論文の出版後に付け直されています。論文で使われたデータそのものは入手できませんでした。

## 5. 再実行の方法
```bash
uv sync
uv run python src/load_fullcsv.py          # authors: CSV -> data/processed/fullcsv.parquet
uv run python src/convert_raw.py "<labelled.csv>" data/processed/lmd2023_1.75M_labelled.parquet
uv run python src/preprocess_public.py     # public15 の15特徴を作成
uv run python src/run_repro.py --dataset authors --protocol cv10 --models DT   # モデル単位で実行
uv run python src/run_dnn.py --dataset authors --models MLP
uv run python src/summarize.py             # results/repro_summary.{csv,md}
```
- 結果の生データ（モデル×foldごとのJSON）：`results/repro/<dataset>/<protocol>/`
- 集計：`results/repro_summary.csv`
- データの入手元：著者の Google Drive（`LMD-2023.rar`、`full-csv(Evaluated Titles).rar`）、ETCExp リポジトリの `RBPolicy.rar`
